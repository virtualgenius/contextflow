Classroom and enterprise readiness

Four new UI surfaces from the readiness epic. Everything else in that epic (sample-id fix, local-only mode, headcount, the three classroom bugs) has an existing mockup or needs none.

Options per section; recommended is Della's pick with the reason under each.

1. Starting a map from a template inside a workspace

A · "Start from" dropdown in the New map dialog

New map

  • One extra control; the map name pre-fills from the template so a participant types nothing but their name.
  • Every template is always visible, so participants can pick the wrong one on a projector-driven instruction.
B · Workspace starter set by the instructor; the dialog shows two choices · recommended

New map

Workspace settings (instructor)

Any built-in example, or any map already in this workspace. Each participant gets their own copy.

  • The instructor decides once; every table sees the same two buttons. On a projector that is the whole instruction: "click Workspace starter".
  • "A map in this workspace" as a starter is what makes it enterprise-useful: an architect seeds the org's context map and each team copies it.
  • Copy semantics: same as Duplicate today (new ids for everything), so nothing links back to the starter.
