Gaps worth knowing about

  • Tests are not enforced anywhere automated. The suite takes about five seconds, so adding npm run test:run to the pre-push hook and the CI build job is a one-line change each.
  • Worker integration test fails when the local worker is down. Two tests expect a server on port 8787 and fail instead of skipping. Run npm run dev:local first, or they read as red.
  • No browser-level tests. Real WebSocket sync, offline and reconnect, file import, and canvas drag are only verified by hand. The Playwright plan in docs/TESTING_STRATEGY.md was never implemented.
